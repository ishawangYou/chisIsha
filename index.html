關於我

15年 UX / UI 設計背景 美國 NGH 認證催眠師 量子催眠進修中 NAHA / IFA 芳療進修中

做了15年UX/UI設計師和前端工程師，某天發現自己不想在專業被消磨、失去創新空間的環境裡，一路將就到退休——於是我選擇離開，去追一份真正讓自己感覺「活著」的工作。

現在的我，是美國NGH認證催眠師，也持續進修量子催眠、NAHA / IFA芳療認證。我用催眠和精油，陪伴被焦慮、壓力、失眠困住的人，找回身與心的安定。

SELF CHECK

體質自測

花幾分鐘認識現在的自己，測驗結果僅供自我覺察參考，不是醫療診斷喔。

採用中華中醫藥學會公告的「中醫體質分類與判定」標準量表，共 67 題。請依照近一個月的真實體驗回答，點選答案就會自動跳下一題，大約需要 8～10 分鐘。

測驗結果僅供自我覺察參考，不能取代專業醫療診斷。
